# CrewReady — прототип для NASA Space Apps 2026

Проверка внимания перед критической операцией на МКС: сон и сонливость → тест реакции на 25 с → сравнение «Сегодня / Обычно» → репетиция ключевого шага (захват Cygnus, HOLD → CAPTURE) → договорённость с напарником.

## Запуск

Открыть `index.html` в браузере или запустить локальный сервер:

```bash
python3 -m http.server 8765
```

## Два режима

- **Try the reaction test** — живой тест для жюри. История хранится в localStorage этого браузера; сравнение появляется после 5 завершённых проверок.
- **Run crew scenario** — симулированный астронавт: 5 прошлых проверок (медиана 280 мс, сон 7 ч 20 мин) и сегодняшняя (350 мс, 5 ч 10 мин, сонливость 4/5) → карточка «Review before task».

## Где что настраивать (`app.js`, начало файла)

| Константа | Значение | Смысл |
|---|---|---|
| `TEST_MS` | 25000 | длительность теста (у NASA на МКС — 3 мин) |
| `ISI_MIN/ISI_MAX` | 1500–4000 мс | случайная пауза перед сигналом |
| `RESPONSE_WINDOW` | 1500 мс | нет нажатия → пропуск |
| `ANTICIPATION_MS` | 100 мс | быстрее → раннее нажатие |
| `RULE` | 20% / 120 мин / 4 из 5 | правило карточки Review before task |
| `CREW` | — | данные симулированного астронавта |
| `OPS` | 7 операций | у остальных 6 пока стоит `ready: false` |

## Управление

- Тест: `Space` или клик/тап по панели; `Esc` — отмена. При скрытии вкладки тест прерывается.
- Репетиция: `←` `→` — прицел, `Space` — захват (только при CAPTURE). Есть экранные кнопки.
